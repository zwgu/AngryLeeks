# 愤怒的韭菜（Angry Leeks）

一款"愤怒的小鸟"式**弹弓物理闯关**微信小游戏（双端：微信小游戏 + 浏览器 UMD）。
韭菜们受够了被收割，拿起弹弓从**山脚韭菜地**一路打到**山顶黑宫**——把游资狗、量化狐、主力狼、
空头熊、机构虎、庄家狮统统砸扁，最后战胜金牛 BOSS、冲进黑宫、解放世界！

> 全部图形 **Canvas 实时绘制**、全部音效 **WebAudio 合成**（含结局烟花人群欢呼），
> 无任何图片/音频资源依赖，即拷即用。

🎮 **在线试玩**：[https://game.umyrobot.com](https://game.umyrobot.com)（桌面 / 手机 / 微信内置浏览器均可，首次访问需同意测试版隐私协议）

## 玩法

- **拖动弹弓**：在弹弓附近按住向后拖（手指在反方向）→ 蓄力瞄准 → **松手发射**（直线弹道）
- 韭菜弹丸撞击敌人/建筑造成伤害，砸塌支撑结构敌人会摔落；敌人会发射激光反击（主角 12 颗心 HP）
- 打碎敌人/方块掉落**积分（¥）**；清光本关敌人即过关；剩余弹丸 ≥2 → ★★★、=1 → ★★、=0 → ★
- 过关积分可进武器库**购买新武器 / 升级武器**（Lv1→Lv5，每级 +25% 伤害）
- 底部「重置」按钮：一键清空积分 · 头像 · 武器（弹窗确认）

## 运行

### 微信开发者工具（真·微信小游戏）

1. 打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（选择"小游戏"类型）
2. **导入项目** → 目录选择本项目根目录
3. AppID 选「测试号」或自己的小游戏 AppID
4. 工具自动运行 `game.js`；真机点「预览」扫码

### 浏览器

直接双击打开 `index.html`，或 `python -m http.server 8000` 后访问 `http://localhost:8000/`。
线上版已部署至 [https://game.umyrobot.com](https://game.umyrobot.com)（Nginx + Let's Encrypt HTTPS，http 自动跳 https）。

## 代码结构（js/game-core.js）

| 模块 | 说明 |
| --- | --- |
| Sound | WebAudio 合成音效：发射/碰撞/金币/激光/核爆 + 结局人群欢呼（`cheer()`） |
| 输入 | 微信 `wx.onTouch*` 与浏览器 mouse/touch 双适配；触摸坐标经 `toLogical()` 换算 |
| 物理 | 直线弹道（`AIM_SPEED` 直飞），1/180s 子步碰撞判定；穿透型武器 hitSet 去重 |
| 关卡 | 6 关声明式布局，梯田金字塔山体；`item=[kind, cxOff, yUp, w, h, elite?]` |
| 武器库 | 积分购买 + 升级（`LV_COST=[0,200,500,1000,2000]`，每级 +25% 伤害） |
| 渲染 | 纯 Canvas：天空渐变/太阳/立体云/山体梯田/弹弓木纹/毛玻璃 HUD/武器精绘 |
| 存档 | 微信 Storage / localStorage 双端（积分/武器/星级/头像/静音/隐私协议） |
| 结局 | FINAL 动画：抓牛冲黑宫 → 烟花齐射 → 人群欢呼 → 结算按钮 |

## 自定义关卡

在 `js/game-core.js` 的 `LEVELS` 数组追加一项：

```js
{
  name: '第 7 关 · 自定义',
  leeks: 5, weapon: 'stone', hint: '自定义提示语',
  items: [
    ['plank', 0, 40, 130, 16],          // [类型, 横向偏移, 距本关台面高度, 宽, 高]
    ['wolf', 0, 56, 52, 58, true]       // 可选第 6 参 elite（精英怪）
  ]
}
```

可用类型：`plank / leg / brick / stone`（建筑）+ `bull / wolf / fox / bear / dog / tiger / lion / whitehouse`（敌人）。
